FIN AI MEDIA — архив для Timeweb Cloud

Состав:
- package.json — команда запуска;
- server.mjs — сервер сайта без дополнительных библиотек;
- Dockerfile — вариант запуска через контейнер;
- dist — весь сайт, страницы, калькуляторы, JavaScript и изображения.

Автоматический запуск:
1. Загрузите содержимое архива в репозиторий или приложение Timeweb Cloud.
2. Среда: Node.js 20 или Docker.
3. Команда запуска: npm start.
4. Порт задаётся автоматически переменной PORT. Вручную указывать его не нужно.

Важно:
- файлы package.json, server.mjs и папка dist должны находиться в корне проекта;
- не загружайте одну дополнительную внешнюю папку;
- после запуска привяжите домен в настройках приложения;
- SSL-сертификат Timeweb выпускает после корректной привязки домена.
